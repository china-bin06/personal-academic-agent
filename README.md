# 个人学业 Agent

当前版本：**v0.2.0**（本地单用户）。

基于 FastAPI、Pydantic、LLM Tool Calling 和 PostgreSQL，
查询个人成绩、课表和培养计划。

## 功能

- 百分制成绩汇总与学期比较
- 指定教学周的课表查询
- 培养计划学分进度查询
- PDF、Excel 和网页 HTML 数据解析
- 受控查询工具、参数校验和查询审计
- 本地网页问答与数据依据展示
- 上传文件、完整预览和显式确认导入
- 展示导入结果和数据库数据时间
- 培养计划树形展示
- 本地采集日志任务状态页面

## 技术栈

Python、FastAPI、Pydantic、SQLAlchemy、PostgreSQL、
Playwright、pdfplumber、原生 HTML/CSS/JavaScript。

## 本地使用

1. 创建 Python 虚拟环境并安装 requirements.txt。
2. 根据 .env.example 创建 .env，配置数据库和模型服务。
3. 启动 PostgreSQL，完成数据库迁移及只读账号配置。
4. 采集或准备个人数据，预览确认后正式导入。
5. 启动 FastAPI：

    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

6. 打开 http://127.0.0.1:8000/。

## 数据说明

仓库不包含真实成绩、课表、培养计划、登录状态或密钥。
部分测试需要本地数据文件及数据库，不能在空数据环境下直接运行。

## 当前限制

- 当前用于本地单用户。
- 问答请求不保存多轮对话上下文。
- 命令行培养计划采集仍需人工确认页面；页面采集入口可自动检查并展开，登录失效时手动登录后继续。
- 课表按常规教学安排查询，不包含临时调课。
- 课表PDF需要同学期已确认的参考JSON；新学期没有参考时，请上传完整课表JSON。
- 采集任务页支持启动课表、成绩和培养计划采集；原日志中的“started”仍不认定为进程正在运行。

## 第二版使用

打开首页的“数据导入 → 手动导入”：选择数据类型和文件，点击“上传并预览”，核对完整结果后点击“确认导入数据库”。

- 成绩：`.xlsx`；培养计划：UTF-8 `.html` / `.htm`；课表：`.json` / `.pdf`。
- 单文件最多10MB，预览有效期30分钟；预览不写入学业数据库。
- 预览暂存到 `data/previews/previews.sqlite3`，确认文件保存到 `data/uploads/`，均被 Git 忽略。
- 课表PDF参考文件为 `data/candidates/schedule-学年-学期.json`，例如 `schedule-2026-2027-1.json`。
- 数据时间来自数据库，不代表教务页面的最新发布时间；重复导入未变化时数据时间保持不变。
- 确认超时可以在预览有效期内重试同一个预览；预览过期后重新上传。
- 原CLI采集和导入脚本仍然可用，不需要数据库迁移或新增依赖。

接口和设计详见 [第二版设计与核验](docs/v0.2.0.md)。

首页“数据导入 → 自动导入”可选择类型及学期、开始采集、登录后继续、取消和查看预览；两种方式共用预览及确认导入区域，预览注明来源。“本地采集任务状态”保留任务与日志展示。采集完成不会直接入库。使用与验收见 [页面自动采集](docs/page-collection.md)。

首页默认只显示学业问答，回答紧接提问区域，示例问题可展开。功能列表点击后分别显示数据导入、数据时间、培养计划和采集任务，支持浏览器前进后退与刷新。培养计划树可展开课程明细，数据读取自同一已导入快照，无需重新采集或迁移数据库。

在独立的“开学日期同步”功能中确认当前学年、学期、第一教学周周一及教学周范围后，可直接提问“明天有什么课”。配置保存在本地SQLite数据库，本页显示配置及保存时间，“数据时间”页继续只展示已导入学业数据。日期工具按北京时间换算，未配置或超出范围时请求补充信息。顶部图片可以调节大小。说明见[日期课表与界面优化](docs/calendar-and-display.md)。
