# 功能导航与培养计划明细

本次优化范围：问答布局、功能导航、培养计划展示接口与课程明细。没有更改问答工具返回、统计规则、采集脚本、正式导入服务或数据库结构。

- 首页只展示学业问答，提问与回答位于同一卡片；示例问题折叠在下方。
- 功能列表提供问答首页、数据导入、数据时间、开学日期同步、培养计划、采集任务。每次仅展示一个功能，切换保留表单、回答和后台任务状态。
- URL片段支持直达、刷新及前进后退；进入数据时间、培养计划和任务页面时读取相应数据。
- 自动采集仍在后台执行，完成后的预览会切换到数据导入区域。
- 培养计划展示接口读取摘要选定的同一snapshot_id中的courses JSONB，按课程模型校验后放入tree，不添加到问答工具的nodes摘要中。
- 课程表复用预览组件，展示课程名、课程代码、学分及页面原始修读状态，不将“已修”自动判定为“已通过”。
